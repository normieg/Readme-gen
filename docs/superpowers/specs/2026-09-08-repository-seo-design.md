# Repository SEO Design

## Goal

Improve discovery of `normieg/Readme-gen` on GitHub and search engines while keeping its positioning accurate, concise, and useful to people using Codex, Claude Code, or another Agent Skills-compatible tool.

## Audience and positioning

The repository will target all compatible coding agents equally. Its primary search phrase and product identity will be **AI README generator skill**. Supporting language will naturally cover GitHub README generation, repository-aware documentation, Markdown, Codex, Claude Code, Agent Skills, Mermaid diagrams, badges, and README auditing.

## Repository README

The root README will retain its detailed installation and reference material, with the opening reorganized for discovery and conversion:

1. Use `AI README Generator Skill` as the H1.
2. Add a concise value proposition that explains what the skill does and names its supported agent ecosystem.
3. Place the existing quick-install command near the top.
4. Add a compact capability summary using only claims supported by `readme-gen/SKILL.md` and the bundled references/templates.
5. Preserve substantive installation, package, usage, validation, and boundary details.
6. Avoid keyword stuffing, unverifiable claims, fake metrics, and decorative badges that do not communicate verified status.

## GitHub metadata

Update the repository About panel with:

- Description: `AI README generator skill for Codex, Claude Code, and Agent Skills—create, audit, and improve repository-aware GitHub documentation.`
- Website: leave blank because the repository has no separate verified project site.
- Topics: `readme-generator`, `github-readme`, `agent-skills`, `codex`, `claude-code`, `documentation`, `markdown`, `mermaid`, `ai-agents`, and `developer-tools`.

The repository name will remain unchanged to avoid breaking existing URLs and installation commands. No social-preview image, release, license, or homepage will be invented.

## Validation

- Confirm the README title, opening copy, headings, and installation links render correctly.
- Check Markdown links and repository-relative paths.
- Confirm the diff contains only SEO-related documentation changes and this design record.
- Verify the public GitHub About description and topics after saving them.

## Success criteria

- The public repository immediately communicates that it is an AI-powered GitHub README generator for multiple coding agents.
- Important search phrases appear naturally in the H1, opening paragraphs, headings, and GitHub topics.
- Existing installation and operational documentation remains accurate.
- GitHub displays the new About description and all selected topics.
